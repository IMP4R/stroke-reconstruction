# Абстрактная задача: восстановление росчерка по растру

## Постановка

Есть grayscale-изображение (220×154, но алгоритм должен быть размеро-независимым).
На нём:
- **серая ломаная линия** — след одного непрерывного движения пера (один росчерк,
  перо не отрывается; толстые места = перо прошло по одному месту дважды);
- **тёмная жирная точка** — место, где перо коснулось поверхности (старт).

Линия может пересекать саму себя (пересечение — это проход «сквозь», не развилка),
иметь плавный прогиб руки и слегка переменную ширину.

## Требуемый результат

Для каждого изображения построить **простейшую ломаную**, описывающую росчерк:

1. упорядоченный список угловых точек `(x, y)` в порядке движения пера от стартовой точки;
2. количество отрезков (линий) в этой ломаной.

Правила, выведенные из данных:
- в точке старта линия либо заканчивается (росчерк открытый), либо стартовая точка
  лежит **на середине** одной из линий — тогда росчерк заканчивается, вернувшись в неё;
- на пересечениях перо идёт **прямо** (сквозь), а не поворачивает;
- двойная линия (толстое место) проходится **туда-обратно**;
- лишних линий быть не должно: сегмент существует только там, где есть чернила;
- класс фигуры определяется числом отрезков (2 = «галка», 3 = «треугольник/z»,
  4 = «прямоугольник/стрелка», 5 = «звезда»; округлые петли — отдельный класс).

## Данные

- `images/fig_001.png … fig_100.png` — входные растры.

## Черновые скрипты (рабочие, но не доведённые)

- `scripts/path_extract.py` — текущий конвейер: бинаризация → скелетизация (thin 1px) →
  граф цепочек → обход Флёри с мостами (приоритет прямой на пересечении, переходы
  только по чернилам) → канонизация полилинии по кривизне (`poly_canon`) →
  отбор вершин на выпуклой оболочке → жадный тур по чернилам с критерием
  «непрерывность направления пера» → схлопывание дублей, отсечение почти-прямых углов.
- `scripts/verify_lines.py` — подсчёт числа линий по ломаной (порог отладочный).
- `scripts/geo_stand.py` — метрики качества: покрытие линии штрихом (cov_stroke),
  доля точек вне чернил (offline), максимальное отклонение, старт из точки.

## Текущее состояние (на чём остановились)

- Открытые фигуры (галка, x-образные, n-образная) решаются верно: 2–3 отрезка,
  порядок от точки как у генератора.
- Замкнуто-обходные (звезда-контур, прямоугольник, треугольник) дают на 1 отрезок
  меньше: эвристики замыкающей стороны то срабатывают на фантомном возврате
  (галка), то блокируют настоящий остаток стороны (звезда).
- Стрелка: возвратный проход по крылу (туда-обратно) восстанавливается нестабильно.
- Округлые петли — вне области задачи.

## Что проверять при разборе

1. `extract_path(path)` → плотный путь; `stroke_corners(path)` → ломаная + старт.
2. Матрица ожиданий: галка=2, треугольник=3, прямоугольник=4, звезда=5 отрезков.
3. Каждый сегмент ломаной должен лежать на чернилах по всей длине (±прогиб руки);
   сегментов «через пустоту» быть не должно.
