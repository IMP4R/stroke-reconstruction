# Новая обводка по центральной линии

Реализация с нуля: `scripts/trace_stroke.py`. Старые три скрипта и `images/` не изменяются и новым кодом не импортируются.

## Запуск

Зависимости: Python 3, numpy, scipy, scikit-image, Pillow.

```bash
cd /home/user/figure_stroke_dataset
python3 scripts/trace_stroke.py images --output fresh_output
python3 scripts/build_review.py
open fresh_output/review.html
```

Один файл:

```bash
python3 scripts/trace_stroke.py images/fig_025.png --output fresh_output
```

## Результаты

- `fresh_output/review.html` — автономный просмотр всех 100 фигур, анимация движения, ползунок, переключатель точного вектора. Не требует сервера.
- `fig_XXX.json`: `path` — упорядоченный плотный путь; `vector` — его упрощённая векторная полилиния; координаты `(x,y)` в исходном изображении.
- `fig_XXX.svg` — вектор без исходного растра, без команды замыкания `Z`.
- `fig_XXX_overlay.png` — оригинал с тонким цветным маршрутом. S — старт, E — конец. Синий → красный соответствует времени, а не разным компонентам.
- `summary.json` — диагностическая сводка.
- `validation.json` — результаты механических проверок по всем входам.

## Правила

1. Только чернила одной связной компоненты со стартовой точкой. Разрывы не склеиваются, морфологического замыкания нет.
2. Скелет превращается в цепочки. Пиксельная область пересечения считается одним узлом, чтобы не принимать внутренние ступеньки растра за новые развилки.
3. В пересечении выбирается продолжение с наименьшим изменением касательной. Никакого обхода Флёри/Эйлера, выпуклой оболочки, тура между углами и принудительного покрытия всех веток.
4. У трёхлучевой стрелки достаточно толстое терминальное крыло получает два прохода. Сначала оно проходится наружу и обратно, затем оставшееся крыло. Обычный тонкий тупик не даёт права на обратный проход.
5. Упрощение полилинии разрешено только если весь новый отрезок остаётся на маске чернил. Скачки через пустоту запрещены и на этапе экспорта. Возвратная вершина не удаляется.

`vector_segments` — число отрезков точного вектора, **не класс фигуры**. Слегка кривая сторона может состоять из нескольких отрезков: это намеренно, иначе прямая хорда могла бы срезать изгиб и уйти с линии. Этот алгоритм восстанавливает обводку, а не угадывает «треугольник/звезда».

## Ограничения и честные статусы

`complete` означает, что пройдены все выделенные цепочки стартовой компоненты; это не доказательство правильного распознавания стартовой точки или неизвестного порядка генератора. `untraced_branches` означает, что трассировщик остановился, не придумывая соединение к остаткам. `disconnected_ink_pixels` показывает другие компоненты, куда алгоритм не перескакивал.

Слишком близкие пересечения могут слиться в одну пиксельную область; при резком изгибе непосредственно за пересечением оценка касательной по короткой хорде может выбрать неверную ветку. Эти случаи не представлены надёжным ground truth в данном наборе. Обычный знак «+» намеренно проходится прямо до конца: алгоритм не возвращается по тонкой линии ради покрытия остальных рук.

Очень короткое крыло стрелки длиной в несколько толщин линии может слиться с пиксельной областью угла: такие изображения требуют дополнительного различения угла и реальной ветки. Проверка на данном наборе не доказывает корректность на любых произвольных картинках.

Порог чернил относителен контрасту изображения. Если видимая линия слишком слаба относительно остального изображения, порог может её потерять; алгоритм не имеет права компенсировать это скрытой склейкой. Предполагается одна фигура на светлом фоне и выраженная стартовая точка. На неразрешимом симметричном старте исходный порядок по одному растру в общем случае не восстанавливается однозначно.

## Проверки

```bash
python3 -m unittest discover -s scripts -p 'test_trace_stroke.py' -v
python3 scripts/validate_dataset.py
```

Синтетические проверки: белый разрыв, поворот, прямой проход пересечения, повтор толстого крыла, запрет повторения тонкой ветки, сохранение разворота, запрет хорды через пустоту, несколько масштабов, CLI и экспорт.

Стандартный behavior-map extractor на этих обычных Python-функциях вернул 0 узлов — его «100% от 0» не является покрытием. Поэтому `validate_dataset.py` дополнительно перечисляет все функции через AST и сообщает долю упоминаний в тестах; это всё ещё **не branch coverage**. Результаты на 100 растрах и визуальный просмотр учитываются отдельно.
